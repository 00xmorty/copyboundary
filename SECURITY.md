# Security policy

CopyBoundary is a read-only preflight, not a secure copy boundary or sandbox. Only the latest release is supported. Do not run against hostile or concurrently changing filesystems. No telemetry or automatic uploads.

Please report suspected vulnerabilities through GitHub private vulnerability reporting if available, otherwise open a minimal issue without exploit payloads, private paths, usernames, secrets or logs. Reports contain relative filenames: review and redact them yourself. Never upload a real confidential directory snapshot.
